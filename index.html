Beelink Backups

A personal backup utility operated by TJReed222.

What it does

Beelink Backups uses rclone to upload, verify, and restore personal backup files in the owner's Google Drive account. It supports backups of media and application configuration.

Google Drive access

The utility requests the drive.file permission to create and manage files it creates in the authorized account. Access is used for backup transfers, verification, restoration, and owner-configured retention.

This utility is for the owner's personal use. There is no public signup or public access to backups.
